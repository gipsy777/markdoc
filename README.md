# markdoc (fork)

This repository is a fork of the original Markdoc project: https://github.com/markdoc/markdoc

Markdoc is a powerful, flexible, Markdown-based authoring framework originally developed by Stripe. This fork currently contains no additional code changes and preserves the original project's MIT license.

If you plan to contribute or customize this project, please sync with the upstream repository, open issues, and create pull requests describing your changes.
